# Project Overview

Streamyn is a modern live event platform built to explore, browse, and interact with events in a clean and responsive interface. It provides users with a smooth experience to discover events, view details, and navigate seamlessly across pages with dynamic UI and animations.

# Tech Stack Used
Frontend: React (Vite)
Styling: Tailwind CSS
Routing: React Router
Build Tool: Vite
Deployment: Render
⚙️ Setup Instructions
1. Clone the repository
git clone https://github.com/shrisantoshini/Streamyn.git
cd Streamyn
2. Install dependencies
npm install
3. Run the project locally
npm run dev
4. Build for production
npm run build
