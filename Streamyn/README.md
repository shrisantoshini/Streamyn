# Streamyn

## Project Overview
Streamyn is a modern, beautifully designed live event streaming platform. It features a fully responsive, dual-theme (Light & Dark mode) UI built to showcase live events, tech talks, music festivals, and sports broadcasts. 

The platform offers a premium user experience packed with features including sleek category filtering, real-time live viewer counts, an elegant Top 3 trending streams ranking with a Netflix-style typography layout, dynamic smooth-scrolling sticky glassmorphic navigation, and a seamlessly animated interface that floats gracefully over beautiful abstract SVG background aesthetics.

## Tech Stack Used
- **Frontend Framework:** React.js powered by Vite for incredibly fast build times and hot-module replacement.
- **Styling:** Tailwind CSS with customized typography, customized keyframe animations (`index.css`), responsive grids, flex layouts, and custom CSS text-strokes.
- **Routing:** React Router (`react-router-dom`) for fluid, fast single-page application (SPA) navigation.
- **Icons & Graphics:** Inline SVGs heavily styled with CSS transitions, structural shapes, animated stroke arrays, drop-shadows, and scalable properties.

## Setup Instructions
To run this project locally, simply follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd live-event-platform
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View locally:**
   Open your browser and navigate to the localhost port provided in your terminal (usually `http://localhost:5173`).
